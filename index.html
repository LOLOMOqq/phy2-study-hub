How to update every lesson

  1. Copy: duplicate lessons/lesson-template.html and rename it.
  2. Edit: update the title, theme class, summary, formulas, examples, and practice.
  3. Link: add the new lesson card/link in index.html (and top nav if you want).
  4. Save & refresh: open your browser and refresh the page.

Tip: change the lesson background by setting the body class, e.g. <body class="theme-electric">. You can create new themes in assets/style.css.

Edit the HTML files, save, and refresh. No build tools needed.
