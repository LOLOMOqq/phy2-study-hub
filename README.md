`# PHY2 Study Hub

A simple, updatable static website for PHY2 lesson reviewers (easy-to-understand explanations, formulas, examples, and practice).

## Open locally
- Open \`index.html\` in any browser (phone, tablet, laptop).
- No build tools or install needed.

## Use on all gadgets (publish as a website)
Because this is a static site (HTML/CSS/JS), you can host it for free so it works on any device with a link:

### Option 1: GitHub Pages (easy)
1. Create a GitHub repo and upload the contents of this folder.
2. In repo **Settings → Pages**, set Source to your main branch (root).
3. GitHub will give you a URL like \`https://<username>.github.io/<repo>/\`.

### Option 2: Netlify / Vercel / Cloudflare Pages
1. Drag-and-drop this folder (or connect the repo).
2. No build command needed; publish directory is the folder root.

## Notes
- **Internet recommended:** MathJax (equations) loads from a CDN and concept illustrations are hotlinked from Wikimedia Commons (with attribution). The text content still works offline.
- **Themes:** background themes are selectable and saved in the browser.
- **Add lessons:** duplicate \`lessons/lesson-template.html\`, edit it, then link it from \`index.html\`.
